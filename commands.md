pwd`: Prints the current working directory.
2. `cd`: Changes the directory.
3. `cd /`: Changes to the root directory.
4. `ls`: Lists files and directories in the current directory.
5. `cd bin`: Changes to the `bin` directory.
6. `vim bin`: Opens the `bin` directory using the `vim` editor (note: incorrect, it's meant to be used for files, not directories).

8. `touch hello.txt`: Creates an empty file named `hello.txt`.
9. `echo "My name is Piyush Yadav" > hello.txt`: Writes the text "My name is Piyush Yadav" into the file `hello.txt`.
10. `cat hello.txt`: Displays the content of the file `hello.txt`.
11. `head hello.txt -n 1`: Displays the first line of the file `hello.txt`.
12. `tail hello.txt -n 3`: Displays the last three lines of the file `hello.txt`.
13. `sudo apt update`: Updates the package lists for the system.
14. `sudo apt install nginx`: Installs the Nginx web server.
15. `df -h`: Displays disk space usage in human-readable format.
16. `sudo chmod 400 hello.txt`: Changes the permission of the file `hello.txt` to read-only for the owner.
17. `sudo chown mobile hello.txt`: Changes the ownership of `hello.txt` to user `mobile`.

22. `mkdir logs`: Creates a directory named `logs`.

25. `git init`: Initializes a new Git repository in the current directory.
26. `git add <file>`: Adds the specified file to the staging area in Git.
27. `git commit -m "<message>"`: Commits changes in Git with a message.
28. `git branch dev`: Creates a new branch named `dev` in Git.
29. `git switch dev`: Switches to the `dev` branch in Git.
30. `history`: Displays the command history.
